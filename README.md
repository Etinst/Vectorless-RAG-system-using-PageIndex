# Vectorless RAG using PageIndex

## Overview
This project implements a Vectorless Retrieval-Augmented Generation (RAG) pipeline using PageIndex and LLM-based hierarchical search instead of traditional vector databases.

## Features
- Vectorless document retrieval
- LLM-powered tree search
- Context-aware querying
- Large document processing
- No embedding/vector database dependency

## Tech Stack
- Python
- Jupyter Notebook
- PageIndex
- OpenAI API
- LangChain
- RAG Architecture

## Usage
1. Install dependencies
2. Add API keys
3. Run the notebook cells sequentially
4. Query documents using the implemented pipeline

## Project Goal
To improve retrieval accuracy and reduce dependency on traditional embedding-based vector search systems.
